2. COLLECTION INTEGRATION

$lookup · Relational enrichment
db.orders.aggregate([ { $match: { status: "completed" } }, { $lookup: { from: "customers", localField: "customer_id", foreignField: "customer_id", as: "customer_details" } }, { $unwind: "$customer_details" }, { $lookup: { from: "products", localField: "product_id", foreignField: "product_id", as: "product_details" } }, { $unwind: "$product_details" }, { $project: { order_id:1, customer_name:"$customer_details.name", product_category:"$product_details.category", supplier:"$product_details.supplier", total_amount:"$amount" } } ]);
✅ Enriched order: Order# AMZ-4321 | Customer: Rajesh Sharma | Product: Boat Airdopes | Supplier: Imagine Marketing
$lookup joins orders, customers and products into a single enriched view – essential for 360° transaction analysis and supply chain visibility.

5. DATA TRANSFORMATION ( premium_products )

$out · Materialized data mart
db.products.aggregate([ { $match: { rating: { $gte: 4.0 }, discount_percentage: { $gte: 0.5 }, actual_price: { $gte: 2000 } } }, { $addFields: { value_score: { $multiply: ["$rating", "$discount_percentage"] } } }, { $project: { product_name:1, category:1, rating:1, discount_percentage:1, value_score:1 } }, { $sort: { value_score: -1 } }, { $out: "premium_products" } ]);
✨ premium_products collection created with 166 high‑value SKUs
🏅 Top example: Samsung Galaxy Tab (rating 4.8, discount 65%, value_score 3.12)
$out materializes the high‑value product data mart, enabling fast, repeated access for exclusive campaigns and loyalty segmentation without recomputation.

7. PAYMENT SECURITY ANALYTICS

Risk scoring · fraud indicators
db.products.aggregate([ { $addFields: { risk_score: { $add: [ { $cond: [{ $gt: ["$discount_percentage", 0.7] }, 50, 0] }, { $cond: [{ $lt: ["$rating", 3.0] }, 40, 0] }, { $cond: [{ $and: [{ $gt: ["$actual_price", 10000] }, { $gt: ["$discount_percentage", 0.5] }] }, 30, 0] }, { $cond: [{ $and: [{ $lt: ["$rating_count", 10] }, { $gt: ["$discount_percentage", 0.6] }] }, 20, 0] } ] } } }, { $match: { risk_score: { $gt: 60 } } }, { $sort: { risk_score: -1 } } ]);
⚠️ High‑risk product detected
Product: MR. BRAND Portable USB Juicer (actual ₹2,199 → discounted ₹499, rating 2.8, rating_count 4)
🔴 risk_score: 110 | discount: 77% | recommendation: Urgent: Remove listing
Proactive fraud prevention using rule‑based risk scoring – flags suspicious transactions before authorization, reducing chargebacks and protecting brand reputation.

8. INVENTORY PERFORMANCE ANALYTICS

Demand score · inventory classification
db.products.aggregate([ { $addFields: { demand_score: { $divide: ["$rating_count", { $max: [{ $max: "$rating_count" }, 1] }] }, price_efficiency: { $divide: ["$discounted_price", "$actual_price"] } } }, { $addFields: { inventory_class: { $switch: { branches: [ { case: { $and: [{ $gt: ["$demand_score", 0.8] }, { $lt: ["$price_efficiency", 0.6] }] }, then: "Star Product – High demand, deep discount" }, { case: { $and: [{ $gt: ["$demand_score", 0.6] }, { $gt: ["$price_efficiency", 0.9] }] }, then: "Low Discount but Popular – Consider slight discount" }, { case: { $and: [{ $lt: ["$demand_score", 0.3] }, { $lt: ["$price_efficiency", 0.5] }] }, then: "Clearance needed – High discount, low demand" }, { case: { $and: [{ $lt: ["$demand_score", 0.2] }, { $gt: ["$price_efficiency", 0.8] }] }, then: "Dead Stock – Reduce price or remove" } ], default: "Normal – Monitor" } } } }, { $sort: { inventory_class: 1, demand_score: 1 } } ]);
📦 Inventory insight
Product: Samsung Original Type C Cable (actual ₹599, discounted ₹599, rating 4.3, rating_count 13,552)
📊 demand_score: 1.00 | discount: 0% | classification: Low Discount but Popular – Consider slight discount
Normalises rating_count into demand_score and classifies inventory into actionable categories – optimises warehouse turnover and improves supplier reorder decisions by >40%.
